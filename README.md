# Data Structures & Algorithms Practice Repository 🚀

Welcome to my **Data Structures & Algorithms Practice Repository**! 🚀

This repository contains a collection of practical **C programs and exercises** created to strengthen programming, problem-solving, algorithmic thinking, and data structure implementation skills.

The programs focus on implementing different data structures and algorithms through **simple, understandable, and practical C programs** with runtime user input.

## 💻 Technical Skills

* **Programming Language:** C
* **Data Structures:** Arrays, Linked Lists, Stacks, Queues, Trees
* **Linked Lists:** Singly, Doubly, Circular, Circular Doubly Linked Lists
* **Stack Applications:** Expression Conversion, Expression Evaluation, Palindrome Checking, String Reversal
* **Searching:** Linear Search, Binary Search
* **Sorting:** Bubble Sort, Selection Sort, Insertion Sort, Merge Sort, Quick Sort
* **Trees:** Binary Trees, Binary Search Trees, Tree Traversals
* **Programming Concepts:** Pointers, Structures, Functions, Recursion, Dynamic Memory Allocation
* **Algorithm Concepts:** Time Complexity, Space Complexity, Traversal, Searching, Sorting

## 🎯 Purpose

The main goal of this repository is to build a strong foundation in **Data Structures and Algorithms using C** through hands-on programming exercises.

Each program focuses on a specific concept and is designed to be **simple, understandable, practical, and suitable for academic/laboratory practice**.

Programs generally accept **user input during runtime** and demonstrate the required operations step by step where applicable.
